The Evil Hacker — HTML & CSS Project
A hacker-themed frontend web project built using HTML and CSS.

What it does
Displays a hacker-themed webpage
Uses custom CSS styling for layout and appearance
Organizes webpage content using HTML
Provides a simple frontend web design experience

Technologies Used
HTML5 — semantic structure and webpage layout
CSS3 — styling, layout, colors, and visual presentation

What I learned
Structuring webpages using HTML
Styling web elements using CSS
Linking external stylesheets to HTML files
Organizing project files
Applying CSS classes and selectors
Building and styling a frontend webpage from scratch

How to run
Clone the repository:
git clone https://github.com/AnnabharathiN/TheEvilHacker.git
Open the downloaded project folder.
Open EvilHacker.html in your browser.
Make sure EvilHackerstyle.css is in the correct location so the styles load properly.
